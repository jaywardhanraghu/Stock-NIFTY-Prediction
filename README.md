# Stock-NIFTY-Prediction

This project analyzes the relationship between major NSE-listed stocks and the NIFTY-50 Index. 
It builds predictive models to:
1️⃣ Identify the most correlated stock pairs  
2️⃣ Predict stock price using lag-based features  
3️⃣ Predict NIFTY using multiple stock price features  
4️⃣ Study multicollinearity & evaluate model reliability  

This project follows proper Data Science best practices including 
data cleaning, EDA, model building, diagnostics, and interpretation.

---

## 📌 Dataset
Provided stock OHLC data for:
- ADANIPOWER
- ASIANPAINT
- TCS
- LT
- WIPRO
- NIFTY-50 Index

Daily data over a 1-year period.

---

## 🧠 Problem Tasks
✔️ Find most correlated stock pair  
✔️ Predict high-priced company using lag features of correlated company  
✔️ Extend model using OHLC data  
✔️ Predict NIFTY using all 5 companies  
✔️ Repeat removing multicollinearity  
✔️ Compare models & explain differences

---

## 🛠️ Methodology
- Data Cleaning & Alignment
- Correlation Analysis
- Feature Engineering using Lagged Prices
- Linear Regression, Ridge, Lasso, PLSR
- Variance Inflation Factor (VIF) for multicollinearity
- Model Evaluation using:
  - R²
  - RMSE
  - MAE
  - Residual Diagnostics
